## 🎯 Core Features

### 📊 Automated Experiment Engine
The heart of EdgeResearch. Give it a piece of content, and it creates multiple variations, tests them all, and shows you the winner with clear evidence.

### 🧪 Frozen Eval Testing
This feature ensures your improvements are truly better. EdgeResearch freezes the evaluation criteria, so the results you see are consistent and reliable every single time.

### 🚦 Smart Router System
When you have multiple versions of something, the router intelligently directs traffic to the best-performing version. This is perfect for websites, AI prompts, or any system where performance matters.

### 🛡️ Regression Gate Protection
Worried that a change might break something? The regression gate acts like a safety net. It catches any negative changes before they become permanent, keeping your work safe from harmful edits.

### 📈 Real-Time Results Dashboard
Watch your experiments unfold in real-time. Beautiful charts and graphs show you exactly which version is winning and by how much, making decisions easy.

### 🔄 Continuous Harvesting
The system never stops learning. It continuously gathers new insights from your data, finding even better ways to improve your work around the clock.
